    \caption[Tile topology and object\_fifo queues]{The tile topology of the implementation and the object\_fifo queues

    communicates with main memory and two compute tiles, each of which
    connects to its column's shim through a pair of depth-two
    queues: one for input and one for output. The depth of two allows the
    core to process one chunk while the next is transferred. The
    memory tiles in the middle row are unused, since each core
    consumes a portion of the input disjoint from the others and no
    sharing or redistribution of data between them is required.}
