    \caption[Reading the roofline model]{Reading the roofline model. The sloped segment corresponds to the
    bound $\beta I$ imposed by memory bandwidth, and the horizontal one to the
    bound $\pi$ imposed by compute capacity; the achievable performance is the
    minimum of the two. Because memory bandwidth depends on the size of the
    working set, the sloped segment is not a single line but a ladder of
    parallel lines, one per level of the memory hierarchy, and each measurement
    is compared against the one that corresponds to its own working set. Point
    A is memory-bound and will benefit only from a reduction in data traffic,
    B from compute capacity, while C is far from both ceilings: there the
    limiting factor is not the hardware but the organisation of the
    execution.}
